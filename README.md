# Python-1-Review-analyzer
DZ-1 Анализатор отзывов

Программа принимает список отзывов покупателей с оценками и выводит сводный
отчет: самые частые слова, число уникальных слов, среднюю оценку и
распределение отзывов по настроению.

## Файлы

- `review_analyzer.ipynb` — решение в виде блокнота Google Colab (для сдачи)
- `review_analyzer.py` — тот же код в виде модуля
- `test_review_analyzer.py` — тесты

## Запуск

```bash
python3 review_analyzer.py        # интерактивное меню
python3 -m pytest                 # тесты
```

В Colab: «Среда выполнения» → «Перезапустить и выполнить все». Последняя
ячейка запускает меню и ждет ввода, для выхода введите `0`.
